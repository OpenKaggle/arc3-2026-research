# Contributing

Contributions should preserve the clean-room boundary: add policy notes,
auditable source inventories, tests, and derived research records, but do not
add private credentials, private evaluation material, or restricted organizer
data.

## Cite this repository

Use GitHub's **Cite this repository** action, or copy the canonical entry from
[`CITATION.bib`](CITATION.bib) / [`CITATION.cff`](CITATION.cff).
